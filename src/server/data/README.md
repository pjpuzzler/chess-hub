# Bundled puzzle data

`puzzles.json` (classic) and `anarchy-puzzles.json` (Anarchy style) are generated by `tools/build-puzzles.ts`; do not edit by hand.

- Source: https://database.lichess.org/lichess_db_puzzle.csv.zst
- License: CC0 (Lichess open database)
- Rebuild: `npm run build:puzzles` (downloads ~300 MB to the OS temp folder (`chess-hub-puzzles/`) if not cached, or pass an archive path as the first argument). Needs the `zstd` CLI. Output is deterministic (seeded).

Format: `{ version, source, easy: Row[], medium: Row[], hard: Row[] }`, Row = `[id, fen, moves, rating, themes]` with moves and themes space separated. The FEN is the position BEFORE the opponent's setup move (`moves[0]`).

Selection (see `tools/build-puzzles.ts`):

- Popularity >= 85, NbPlays >= 2000, RatingDeviation <= 80
- 4 to 10 plies in Moves (solver makes 2 to 5 moves)
- Buckets by rating: easy 800-1299, medium 1300-1799, hard 1800-2400
- 900 per bucket: puzzles are grouped by their rarest tactical theme and picked round-robin across groups so common themes do not dominate, then shuffled with a fixed seed
- At most 30% of each bucket may carry the `mate` theme
- Every puzzle is replayed with chess.js; illegal ones are dropped

## Guess the Elo games

`elo-games.json` is generated, do not edit by hand.

- Source: `lichess_db_standard_rated_2025-06.pgn.zst` from https://database.lichess.org/ (CC0). Recorded in the file's `source` field.
- Rebuild: `npm run build:elo` (streams the ~30 GB archive with `curl | zstd -dc` and stops after ~10.6M games, about 4 minutes and a few GB of transfer; nothing is cached). Needs the `zstd` CLI. Output is deterministic (seed 20261029).

Format: `{ version, source, games: Game[] }`, Game = `[movetext, timeControl, result, whiteElo, blackElo]`. Movetext is clean SAN with move numbers (`1. e4 e5 2. Nf3 ...`), no comments, NAGs or result token. `timeControl` is `base+increment` in seconds, `result` is `1-0`, `0-1` or `1/2-1/2`. Names, ids, dates and sites are dropped. Games are pre-shuffled across Elo buckets; take them in order.

Selection (see `tools/build-elo-games.ts`):

- Rated Blitz/Rapid/Classical with base time >= 180 s, Termination Normal or Time forfeit
- Both Elos present and numeric, both RatingDiff tags present, |WhiteElo - BlackElo| <= 150
- 20 to 70 full moves
- Each player appears in at most one game
- 11 buckets of 200 average Elo (600-799 ... 2600-2799), 70 games each, time-control quota 28 blitz / 28 rapid / 14 classical (filled from other classes where scarce)
- Every game is replayed with chess.js, and a checkmate must agree with the Result tag

## anarchy-puzzles.json

Format: `{ version, source, buckets: { enPassant, knightBoost, doubleCheck, smothered, rookSac } }`, same Row format, shuffled with their own seed. Buckets are append-only in spirit: live installs index into them by cursor, so a rebuild keeps every bucket already in the file unless named in `--rebuild=`, and `--anarchy-only` leaves `puzzles.json` untouched.

Shared filters: Popularity >= 85, NbPlays >= 500, RatingDeviation <= 80, 2 to 10 plies. No puzzle appears in two buckets or in classic `hard`. Each bucket's defining property is checked with chess.js, not just the Lichess tag:

- enPassant (400; 3 days a week): tag `enPassant` and some solver move is an en passant capture (about a third on the first move); ratings <= 1900 picked first
- knightBoost (150): tag `underPromotion` and a solver move promotes to a knight
- doubleCheck (150): tag `doubleCheck` and a solver move gives check from two pieces; ratings <= 1700 picked first
- smothered (150): tag `smotheredMate`, final move is a knight mate and every square next to the king is the board edge or the king's own piece
- rookSac (150): tag `sacrifice`, 4+ plies, the solver's first move is a rook move (taking at most a minor piece) and the reply captures that rook; ratings <= 2000 picked first

The 2026-10-29 build had castling, easyMate and hard buckets; they were dropped 2026-10-30 as not fitting the sub. enPassant was rebuilt then from the 2026-10-30 database (2,602 candidates); the other three kept buckets are unchanged.
